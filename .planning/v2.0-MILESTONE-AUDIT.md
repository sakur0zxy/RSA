## Local Setup Warning

The project declares `playwright>=1.48` in base dependencies, but the current Python environment used for this audit does not have Playwright installed. This is an environment setup issue, not a source declaration issue. The intended repair path is:

```powershell
python -m pip install -e .
python -m playwright install chromium
```

`rsa doctor` and `rsa doctor --strict` now expose this condition correctly.
