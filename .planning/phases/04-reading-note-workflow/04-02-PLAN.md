# Plan 04-02: Approved Reading Notes To Formal Records

<objective>
Connect approved reading notes to formal maps and auxiliary research notes through explicit human-confirmed formal writes.
</objective>

<must_haves>
- Implement `rsa formal apply-note --source-note P### --human-confirmed --confirmed-by "name"`.
- Apply only notes with `note_status: approved`, `human_confirmed: true`, `confirmed_by`, and `confirmed_at`.
- Support `note_integration_requests[].request_type` values `add_map_row` and `add_research_note`.
- Reuse map validation for note-derived `literature_map.md` rows.
- Append `agent_research_notes.md` rows only when `note_id` is unique; duplicates or conflicts block the whole write.
- Formal writes must be all-or-nothing and must not overwrite existing formal records.
</must_haves>

<tasks>
1. Extend note validation to validate `note_integration_requests` schema.
2. Add formal note preflight and result dataclass in `formal.py`.
3. Implement structured parser/renderer for `agent_research_notes.md`.
4. Add CLI handler and Chinese success/error messages.
5. Add tests for missing confirmation, unapproved notes, map row conflicts, research-note duplicate conflicts, and successful application.
</tasks>
