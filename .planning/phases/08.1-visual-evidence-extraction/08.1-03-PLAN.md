<threat_model>
- **Threat:** Users treat visual extraction as an approval or formal write step. **Mitigation:** CLI help and README state that visual output is staging/review-only; no `formal` code path is invoked.
- **Threat:** Validation/status commands accidentally mutate candidate files. **Mitigation:** tests compare file content before/after read-only commands.
- **Threat:** Documentation promises advanced image intelligence not implemented. **Mitigation:** docs explicitly name deferred features and route LLM visual interpretation to Phase 9.
</threat_model>
