<threat_model>
- **Threat:** Visual candidate YAML leaks full OCR text, full PDF content, secrets, cookies, or account credentials. **Mitigation:** store only concise `source_text` snippets and Chinese summaries in tracked YAML; keep context packets, crops, OCR intermediates, and binary files local-only.
- **Threat:** Candidate visual evidence is mistaken for formal scientific conclusion. **Mitigation:** schema uses `status`, `confidence`, `evidence_level`, `warning_zh`, and `repair_hint_zh`; no formal write command is added.
- **Threat:** Existing user-provided asset manifests are overwritten. **Mitigation:** append/merge by ID and validate before write; do not delete existing manifest entries.
</threat_model>
