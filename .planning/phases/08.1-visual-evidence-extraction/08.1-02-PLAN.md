# Phase 08.1-02 Plan: PDF Visual Extraction Engine And Context Packets

<objective>
Implement the local PDF visual extraction engine behind Phase 8.1: candidate-mode detection, controlled all-detected/page-specific modes, crop creation, caption/region text capture, conservative degradation, and local-only visual context packets prepared for Phase 9 LLM visual analysis.
</objective>

<must_haves>
<truth id="08.1-D05">Default extraction uses `asset_suggestions` first, then scans the authorized PDF; it does not blindly crop every figure/table unless `--all-detected` is provided.</truth>
<truth id="08.1-D06">Expansion modes include `--all-detected`, `--pages 3,5-7`, and `--asset-suggestions-only`.</truth>
<truth id="08.1-D07">Phase 8.1 prepares `visual_context_packet` and `llm_visual_analysis: not_run`; Phase 9 performs or consumes LLM visual interpretation.</truth>
<truth id="08.1-D08">Unreadable PDFs, low-confidence regions, ambiguous caption binding, unsupported chart types, and missing trace information fail closed or degrade with Chinese `warning_zh` and `repair_hint_zh`; numeric data must not be invented.</truth>
</must_haves>

<threat_model>
- **Threat:** False extraction confidence pollutes Phase 9 scoring. **Mitigation:** preserve conservative statuses (`needs_review`, `ocr_partial`, `visual_only`) and require `warning_zh`/`repair_hint_zh` for degraded candidates.
- **Threat:** The engine invents chart values from images. **Mitigation:** do not implement numeric restoration; set `advanced_analysis.curve_extraction.status: not_run`.
- **Threat:** All-detected mode floods tracked records. **Mitigation:** all-detected is explicit; default candidate mode filters by suggestions, captions, references, and region signals.
</threat_model>
