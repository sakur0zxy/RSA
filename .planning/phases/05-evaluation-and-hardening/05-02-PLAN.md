# Plan 05-02: Trace Summaries And Hardening Docs

<objective>
Make each research round inspectable through a trace summary and document known failure modes with remediation.
</objective>

<must_haves>
- New rounds include `trace_summary.md`.
- `rsa round trace R###_name` regenerates trace summaries from round artifacts.
- Trace summaries include tools used, decisions made, rejected items, uncertain items and human approvals.
- Trace summaries must not modify formal records.
- Add a Phase 5 hardening document with known failure modes and remediation guidance.
</must_haves>

<tasks>
1. Add `trace_summary.md` root and fallback template.
2. Implement `src/rsa_cli/trace.py` to read round README, final summary and optional candidate review table.
3. Update `create_research_round` and CLI round command group.
4. Add tests for initial trace creation, regeneration and read-only formal boundary.
5. Add `05-HARDENING.md`.
</tasks>
