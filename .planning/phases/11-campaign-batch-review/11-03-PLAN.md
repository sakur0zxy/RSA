## Must Haves

<must_haves>
<truth id="D-22">D-22: Review queue 采用状态分组加组内优先级排序，分组顺序为 `blocked`、`needs_review`、`partial`、`auto_triaged`、`ready_for_review`、`completed_staging`。</truth>
<truth id="D-23">D-23: Queue item 最小 schema 包含 `queue_item_id`、source ids、`paper_id` 或 `request_id`、`queue_group`、`priority_score`、`risk_flags`、`reason_zh`、`artifact_links`、`review_decision`、`review_decision_version`、`followup_actions`。</truth>
<truth id="D-24">D-24: `artifact_links` 最小集合包含 campaign、workflow run/report、scoring、scoring review packet、metadata request、batch report；缺失允许 null 但必须有中文原因。</truth>
<truth id="D-25">D-25: `artifact_links` 必须可扩展，旧 parser 必须忽略未知链接键。</truth>
<truth id="D-26">D-26: 组内排序优先使用 `ai_read_priority_score_10`，同分优先低置信、高风险、疑似重复、授权异常、metadata intake。</truth>
<truth id="D-27">D-27: `blocked`、`needs_review`、`partial`、低置信度、高优先级、疑似重复、formal write request、metadata intake request 必须进入 review queue。</truth>
<truth id="D-28">D-28: 高优先级阈值为 `ai_read_priority_score_10 >= 8`，低置信度阈值为 `score_confidence != high`。</truth>
<truth id="D-29">D-29: 轻量 review 标记只更新 review queue 和 review history，不写 formal records。</truth>
<truth id="D-30">D-30: `review_decision` 为 `accepted`、`deferred`、`rejected`、`needs_followup`，不用 `approved`。</truth>
<truth id="D-31">D-31: 保留 `review_decision_version` 和 `followup_actions`，后续细分语义优先放入 `followup_actions`。</truth>
<truth id="D-34">D-34: Batch report 包含 campaign 摘要、处理计数、review queue 摘要、blocked/partial/auth/formal 请求列表、metadata intake 列表、下一步建议和 artifact 链接。</truth>
<truth id="D-35">D-35: Batch report 面向中文监管，不倾倒完整日志、不保存 PDF 正文、长摘录、账号会话或敏感信息。</truth>
<truth id="D-38">D-38: CLI 扩展 `rsa campaign` 命令组，不新增 `rsa batch` 或 `rsa campaign-run`。</truth>
<truth id="D-39">D-39: 新增 `rsa campaign run|resume|pause|queue|report C001`。</truth>
<truth id="D-40">D-40: 普通 run 不重跑 completed staging item。</truth>
<truth id="D-41">D-41: `--dry-run` 不实际调用 workflow。</truth>
<truth id="D-42">D-42: `--items` 和 `--status` filter 只影响当前 run。</truth>
<truth id="D-43">D-43: `pause` / `resume` 通过 run state 控制，不重跑 completed。</truth>
<truth id="D-44">D-44: Campaign rerun 只预留未来接口，不在 v1 实现。</truth>
<truth id="D-45">D-45: 本计划负责 review queue、batch report、CLI、docs/tests 和 GSD closeout。</truth>
<truth id="D-46">D-46: Phase 11 v1 测试覆盖 review queue、batch report、CLI docs/tests 和 formal write 边界。</truth>
</must_haves>

<threat_model>
- **Threat:** Review decision is mistaken for formal approval. **Mitigation:** use `accepted` rather than `approved`, document boundary and test no formal writes.
- **Threat:** Report leaks sensitive logs or copyrighted text. **Mitigation:** report uses summaries and artifact links only.
- **Threat:** CLI command surface splits concepts. **Mitigation:** keep everything under `rsa campaign`.
- **Threat:** Phase 11 absorbs Phase 12 UI or Phase 14 worker. **Mitigation:** docs and verification explicitly defer those scopes.
</threat_model>
