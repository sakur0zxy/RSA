# Phase 11-02 Plan: Campaign Pipeline Runner Pause Resume And Concurrency

## Objective

<objective>
Implement the synchronous Phase 11 campaign runner that processes many campaign items through controlled stage queues. Linked items call the Phase 10 single-paper workflow primitive; queued items generate metadata intake requests. The runner supports conservative concurrency configuration, pause/resume, dry-run and run filters without implementing background workers or formal writes.
</objective>

## Must Haves

<must_haves>
<truth id="D-01">D-01: `linked` item 自动调用 Phase 10 workflow，`queued` item 只能生成 metadata intake request。</truth>
<truth id="D-02">D-02: `queued` 不得直接创建 formal metadata。</truth>
<truth id="D-15">D-15: Phase 11 采用多篇之间小规模流水线并行，每篇内部仍按 Phase 10 顺序链执行。</truth>
<truth id="D-16">D-16: 默认并发为 acquisition 2、reading_draft 2、visual_extraction 1、scoring 2。</truth>
<truth id="D-17">D-17: 并发参数可由 `.rsa/local.yaml` 的 `campaign.concurrency` 长期配置，也可由 CLI flag 临时覆盖。</truth>
<truth id="D-18">D-18: CLI override flags 为 `--max-acquisition`、`--max-reading-draft`、`--max-visual`、`--max-scoring`。</truth>
<truth id="D-19">D-19: 阶段队列流水线允许某篇论文完成 acquisition 后进入 reading_draft，不等待全批 acquisition 完成。</truth>
<truth id="D-20">D-20: 不使用全批次阶段栅栏，也不并发启动多个完整 Phase 10 workflow。</truth>
<truth id="D-21">D-21: 默认异常策略为 `continue_on_error` + `pause_on_auth_error` + `pause_on_formal_request`。</truth>
<truth id="D-37">D-37: Phase 11 v1 是同步 CLI，run state 只预留 worker 字段。</truth>
<truth id="D-38">D-38: 扩展现有 `rsa campaign` 命令组，不新增 `rsa batch` 或 `rsa campaign-run`。</truth>
<truth id="D-39">D-39: 新增 `rsa campaign run|resume|pause|queue|report C001` 命令。</truth>
<truth id="D-40">D-40: `rsa campaign run C001` 默认只处理未完成项，已完成 staging 项不重复运行。</truth>
<truth id="D-41">D-41: `--dry-run` 只生成运行计划和预估队列，不实际调用 workflow。</truth>
<truth id="D-42">D-42: `--items` 和 `--status` 只影响本次 run，被排除项记录为 `skipped_by_filter`。</truth>
<truth id="D-43">D-43: `pause` 标记 run 暂停，`resume` 从 pending/failed/retryable/未完成队列继续，不重跑 completed。</truth>
<truth id="D-44">D-44: Phase 11 v1 不实现完整 campaign rerun，只预留字段供后续升级。</truth>
<truth id="D-45">D-45: 本计划负责 pipeline runner、concurrency、pause/resume。</truth>
<truth id="D-46">D-46: 测试必须覆盖 pipeline 调度、并发参数、pause/resume 和 formal write 边界。</truth>
</must_haves>

<threat_model>
- **Threat:** Campaign run accidentally becomes unlimited parallelism. **Mitigation:** synchronous pipeline state, explicit conservative concurrency fields and no background worker.
- **Threat:** Completed work is overwritten. **Mitigation:** default run skips completed staging items and requires future explicit rerun support.
- **Threat:** Authorization or formal write issues spread across batch. **Mitigation:** policy-specific pause and review queue behavior.
- **Threat:** Runner duplicates Phase 10 internals. **Mitigation:** linked items call Phase 10 workflow primitives.
</threat_model>
