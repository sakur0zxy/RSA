# Phase 08.2 Context: Campaign Foundation

## Decision

提前实现 Phase 11 中不依赖 Phase 9/10 的简单部分，作为插入阶段 Phase 8.2。

## Scope

本阶段只做：

- campaign 数据结构：`01_literature/campaigns/C###.yaml`
- 批量候选导入：CSV / TSV / YAML
- 轻量去重：DOI、URL、title/year/first_author
- 与正式 `metadata/P###.yaml` 的轻量链接
- 队列状态汇总
- 中文 CLI：`rsa campaign create/import/validate/status`

## Non-Goals

本阶段不做：

- AI scoring
- read priority ranking
- workflow orchestration
- acquisition / reading / visual extraction 自动串联
- review UI
- formal write

## Chinese-First Rule

所有用户可见输出、错误、README 和 GSD 文档使用中文优先。字段名、CLI flags、YAML keys 和代码标识保持英文稳定，并在用户可见位置给出中文说明。

## Safety Boundary

Campaign 的 `linked` 只表示候选匹配到现有正式 metadata，不代表已经完成阅读、评分、学术结论或 formal approval。
