## 已确认点

### 1. Phase 角色

- Phase 8.2 是插入阶段。
- 它提前实现 Phase 11 中不依赖 Phase 9/10 的基础队列能力。
- 它不是完整 Campaign & Batch Review。

### 2. Scope

本阶段只包括：

- `01_literature/campaigns/C###.yaml`
- CSV/TSV/YAML 候选导入
- DOI/URL/title-year-author 轻量去重
- 与现有 `metadata/P###.yaml` 的轻量链接
- `rsa campaign create/import/validate/status`

### 3. 非目标

本阶段不包括：

- AI scoring
- read priority ranking
- workflow orchestration
- acquisition / reading / visual extraction 自动串联
- review UI
- formal write

### 4. 安全边界

- `linked` 只表示匹配到现有 formal metadata。
- `linked` 不表示已阅读、已评分、已人工批准或已形成学术结论。
- campaign 候选不能直接写入 formal records。

### 5. GSD 复盘结论

- 初次 Phase 8.2 执行是 GSD-compatible fallback，不是严格逐项交互式 discuss。
- 本次 `gsd-discuss-phase 8.2` 用于补齐 context 与 discussion log。
- 不需要重新执行 Phase 8.2，也不需要重新规划 Phase 8.2。
