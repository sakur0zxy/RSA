# Phase 08.2-01 Plan: Campaign Queue Import Dedup And Status

## Objective

Implement a minimal Campaign Foundation before Phase 9/10: batch candidate queues, candidate import, lightweight deduplication, formal metadata linking, read-only validation/status, and Chinese-first CLI.

## Tasks

1. Add `campaigns_root` config and create `01_literature/campaigns/` in skeleton.
2. Add `src/rsa_cli/campaign.py`.
3. Implement:
   - `create_campaign`
   - `import_campaign_items`
   - `validate_campaign`
   - `campaign_status`
4. Add CLI group:
   - `rsa campaign create`
   - `rsa campaign import`
   - `rsa campaign validate`
   - `rsa campaign status`
5. Add tests for CSV/YAML import, dedup, metadata linking, validation and CLI.
6. Update README, ROADMAP, STATE and REQUIREMENTS.

## Acceptance

- `rsa campaign create` writes `C###.yaml`.
- `rsa campaign import C001 --file candidates.csv` imports rows and marks duplicates.
- Existing `metadata/P###.yaml` can be linked by DOI/title-year.
- `validate` and `status` are read-only.
- No AI scoring, workflow orchestration, UI or formal write is implemented.
