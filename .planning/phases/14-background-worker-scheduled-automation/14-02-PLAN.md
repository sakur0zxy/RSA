<objective>
Add scheduled enqueue and explicit recovery semantics for long-running/local worker tasks.
</objective>

<must_haves>

- `schedule due` enqueues due tasks and advances `next_run_at`.
- `worker run --include-due` first enqueues due schedules.
- Add cancel/recover behavior for queued/running/failed tasks.
- Preserve reserved future interfaces for daemon mode and external schedulers.
</must_haves>

</verification>
