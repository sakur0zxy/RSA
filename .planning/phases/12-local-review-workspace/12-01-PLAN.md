<objective>
Implement the Phase 12 review workspace core: a deterministic review object model, urgency grouping, artifact link normalization, generated-only rebuild cleanup and `review_workspace_manifest.yaml`.

This plan covers D-02, D-03, D-04, D-06, D-07, D-09, D-12 and D-13 from `12-CONTEXT.md`.
</objective>

<must_haves>
- D-02: build one unified review object list that can aggregate campaign queue, blocked/partial items, reading notes, visual evidence, scoring packets, workflow reports and formal write requests.
- D-03: use the urgency-first group order `formal_write_request`, `blocked`, `partial`, `needs_followup`, `low_confidence`, `high_priority`, `auto_triaged`, `completed_staging`.
- D-04: every review object must include title/name, object type, status, Chinese reason/risk text, optional AI score/confidence and evidence links.
- D-06: write a machine-readable `review_workspace_manifest.yaml` with schema version, target, pages, groups, objects, artifact links and actions.
- D-07: support both campaign targets and paper targets in the object collector.
- D-09: links must be relative or project-local and missing files must be explicitly marked with Chinese text.
- D-12: expose a fixed output root through config: `01_literature/review_workspace/`.
- D-13: rebuild cleanup must remove only generated artifacts and preserve user records.
- V2-WORKSPACE-01: local review workspace must support verification, approval, reading draft review, visual evidence review and scoring review without writing formal records.
</must_haves>
