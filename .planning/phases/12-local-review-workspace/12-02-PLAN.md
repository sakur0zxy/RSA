<objective>
Generate the static local review workspace pages and expose the `rsa review` command group for build/status/open/clean.

This plan covers D-01, D-04, D-05, D-08, D-09, D-10, D-11, D-12 and D-14 from `12-CONTEXT.md`.
</objective>

<must_haves>
- D-01: Phase 12 output is a static local review package plus CLI commands, with future Web UI-compatible schema.
- D-04: pages show summary, evidence links, Chinese reasons and suggested actions without inlining full YAML/Markdown bodies.
- D-05: pages display commands only; they do not execute scripts or mutate files.
- D-08: generate `index.html`, `groups/*.html` and `objects/*.html`.
- D-09: generated HTML uses relative links and Chinese missing-file markers.
- D-10: generate an actions checklist with object, reason, formal gate flag, suggested order and copyable CLI command.
- D-11: no inline editing; reasons and notes must flow through CLI command suggestions such as `--reason` and `--reviewer`.
- D-12: implement `rsa review build --campaign C001` and `rsa review build --paper P001`.
- D-14: implement `rsa review status`, `rsa review open` and `rsa review clean --generated-only`.
</must_haves>

<tasks>

## T1. Render static review pages

- Type: implementation
- Files: `src/rsa_cli/review_workspace.py`
- Action:
  - Render `index.html` with overview stats, urgent objects and actions checklist.
  - Render `groups/{group}.html` for each populated urgency group.
  - Render `objects/{review_object_id}.html` with evidence links and suggested commands.
  - Render `actions_checklist.md` for terminal-friendly review.
- Verify:
  - Generated pages contain Chinese headings, group labels and formal gate policy text.

## T2. Implement suggested action generation

- Type: implementation
- Files: `src/rsa_cli/review_workspace.py`
- Action:
  - Generate copyable CLI commands for:
    - campaign queue decisions
    - scoring review decisions
    - note/formal write review hints when applicable
    - workflow resume/rerun/status actions for blocked/partial paper workflows
  - Mark whether each action touches a formal gate.
- Verify:
  - Actions are present in manifest, index page and object detail page.
  - Commands are displayed as text only.

## T3. Add `rsa review` CLI group

- Type: implementation
- Files: `src/rsa_cli/cli.py`
- Action:
  - Add `review build --campaign C001`.
  - Add `review build --paper P001`.
  - Add `review status`.
  - Add `review open`.
  - Add `review clean --generated-only`.
  - Print Chinese success/error messages and keep expected errors traceback-free.
- Verify:
  - CLI smoke tests cover help, build/status/clean and invalid arguments.

## T4. Implement open/status/clean behavior

- Type: implementation
- Files: `src/rsa_cli/review_workspace.py`, `src/rsa_cli/cli.py`
- Action:
  - `status` reads the latest manifest and prints target, object count, action count and index path.
  - `open` opens the generated `index.html` using Python `webbrowser`, failing closed with Chinese text if missing.
  - `clean --generated-only` removes generated HTML/manifest/checklist while preserving user records.
- Verify:
  - Tests avoid launching a real browser by exercising status/clean and unit-testing open failure behavior.

</tasks>
