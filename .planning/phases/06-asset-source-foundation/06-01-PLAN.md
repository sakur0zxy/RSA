# Plan 06-01: Source And Asset Data Model

<objective>
Implement the source ledger and asset manifest data model for formal `P###` papers.
</objective>

<tasks>

1. Add `sources_root` to `ProjectConfig` and include `sources/` in skeleton initialization.
2. Add source and asset templates with Chinese explanations and stable English YAML keys.
3. Create `src/rsa_cli/assets.py` with:
   - source record path helpers;
   - asset manifest path helpers;
   - add, validate and status functions for source records;
   - add, validate and status functions for asset manifests.
4. Ensure source/asset commands only accept valid formal metadata IDs.
5. Copy source files to `01_literature/pdfs/P###/` and asset files to `01_literature/assets/P###/`.
6. Update `.gitignore` so binary PDFs/assets remain local-only while `manifest.yaml` can be tracked.
7. Add focused tests for add/validate/status behavior.

</tasks>

<verification>

- `python -m pytest tests/test_assets.py tests/test_skeleton.py -q`
- `git diff --check`

</verification>

<success_criteria>

- Source records can be created for existing formal papers and fail for missing/invalid papers.
- Asset manifests can be created for existing formal papers and fail for missing/invalid papers.
- Validate/status operations are read-only.
- Binary assets/PDFs remain local-only.
</success_criteria>
