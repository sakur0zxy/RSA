## Areas Discussed

| Area | Decision Summary |
|------|------------------|
| Phase boundary | 插入 Phase 7.1，只补强用户授权浏览器 session，不扩展到 Phase 8 阅读、Phase 9 评分或 Phase 10 编排。 |
| Provider schema | 使用 `source_discovery.custom_providers` + `provider_type: browser_session`，新增 `login_url`、`session_storage`、`session_required`。 |
| Login capture | `rsa source login <provider_id>` 打开登录页，用户手动登录，RSA 保存 Playwright storage state。 |
| Local storage | session 文件保存在 `.rsa/sessions/`，不进入 git，不保存密码，不静默读取已有浏览器 cookies。 |
| Search/download reuse | `source find --provider` 复用 Phase 7 candidate/download 流程；v1 支持 cookie-based direct PDF URL。 |
| Query rules | 继续使用 `url_template` 和 Phase 7 的匹配优先级；`title_only` 不自动下载。 |
| Monitoring CLI | 新增 `source session status|clear`，status 只读，clear 只删除本地 session。 |
| Guardrails | 缺 session、域名不匹配、cookie 不可用、未授权镜像和越界 session path 都 fail closed。 |
| Chinese-first | 用户可见内容中文优先，英文 key/flag/enum 保持稳定并提供中文解释。 |
