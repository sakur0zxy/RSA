# Plan 15-01: Codex OAuth Provider Foundation

## Objective

Add the local-only credential and provider foundation for `codex_oauth`: config defaults, auth discovery, auth import/status/clear helpers, preflight validation and CLI entry points.

## Scope

- Add `src/rsa_cli/codex_oauth.py`.
- Extend `ProjectConfig` with `.rsa/auth` and `reading_draft.llm.codex_oauth` accessors.
- Ignore `.rsa/auth/**` in git.
- Add `rsa llm codex status|import|clear`.
- Add a small `rsa doctor` command that reports the `codex_oauth` provider status when configured.

## Non-Goals

- No web login automation.
- No browser cookie extraction.
- No token refresh implementation.
- No default provider change.
- No formal write path changes.

## Verification

- Unit tests for token discovery, import, status, clear and expired-token blocking.
- CLI tests for help visibility and Chinese failure/success messages.
- Config tests for default extension fields.

## User-Facing Contract

All status and repair hints must be Chinese-first. Token values must never be printed.
