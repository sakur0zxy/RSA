# Plan 15-02: Reading Draft Integration And Documentation

## Objective

Wire `codex_oauth` into the existing reading draft LLM provider abstraction and document the safe setup workflow.

## Scope

- Extend `reading_draft.call_llm_draft` to support `provider: codex_oauth`.
- Use the existing reading draft prompt and schema validation.
- Fail closed when auth is missing, expired, malformed or provider response cannot be parsed.
- Update `rsa.yaml`, README and tests.
- Produce Phase 15 summary and verification artifacts.

## Non-Goals

- No scoring integration in this phase.
- No visual LLM image reasoning in this phase.
- No safety LLM reviewer in this phase.
- No worker scheduling for LLM calls in this phase.

## Verification

- Mock provider HTTP response and confirm `rsa note draft` creates a valid ready-for-review note.
- Confirm missing auth blocks without creating fake notes.
- Run targeted tests and full `pytest`.
- Run `gsd-sdk query state.validate`.

## Extension Contract

The provider module should expose reusable functions so later phases can call the same preflight and response path from scoring, visual analysis or safety review without duplicating auth logic.
