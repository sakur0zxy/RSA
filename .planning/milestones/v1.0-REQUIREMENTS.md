# Requirements 归档: v1.0 Local Harness

**归档时间:** 2026-05-13
**状态:** Complete
**原始来源:** v1.0 archive 前的 `.planning/REQUIREMENTS.md`

## 核心价值

让科研 agent 的每一步输出都能追溯到来源、状态和人工确认，避免把未核验的模型判断混入正式科研记录。

## 已完成 v1 requirements

- [x] **PROF-01:** User can define a research topic profile in YAML with topic id, name, keywords, priority questions, metrics, preferred sources, excluded scope, grading rules and required outputs.
- [x] **PROF-02:** User can validate a topic profile and receive actionable errors for missing required fields or invalid values.
- [x] **ROUND-01:** User can create a bounded research round configuration from a topic profile.
- [x] **ROUND-02:** User can produce a round summary that preserves questions, included/excluded scope, status and next actions.
- [x] **REC-01:** User can store verified paper metadata in stable YAML records with paper IDs.
- [x] **REC-02:** User can generate and validate `paper_index.md` from metadata.
- [x] **REC-03:** User can keep candidates staged until verification review is complete.
- [x] **MAP-01:** User can connect approved papers to topic questions, thesis sections and planned outputs.
- [x] **MAP-02:** User can generate research gap reports from literature map coverage.
- [x] **WRITE-01:** Formal writes require explicit human confirmation and fail on conflicts.
- [x] **NOTE-01:** User can create single-paper reading notes only from provided/local/authorized full text.
- [x] **NOTE-02:** Missing or unauthorized full text produces blocked status, not fake notes.
- [x] **NOTE-03:** Approved reading notes can propose formal map or research-note updates through guarded commands.
- [x] **EVAL-01:** User can run deterministic local eval fixtures and compare against a baseline.
- [x] **EVAL-02:** User can generate trace summaries from round artifacts.
