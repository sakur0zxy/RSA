## 概览

v1.0 交付了一个本地优先的 Python/Markdown/YAML research agent harness，用于可审计文献工作流。它建立了 topic profiles、bounded research rounds、formal metadata gates、candidate staging、literature maps、gap reports、authorized reading notes、formal write guardrails、trace summaries 和 deterministic eval fixtures。

## 里程碑总结

### 关键成果

- 建立 `rsa init`、`validate-profile`、`new-round`、`round`、`map`、`gap`、`note`、`formal` 和 `eval` 组成的本地 CLI harness。
- 建立 metadata-first formal records、paper IDs、index consistency 和 human-confirmed writes。
- 建立 candidate staging 和 verification review，防止未验证发现进入 formal records。
- 建立 literature mapping 和 gap reporting，将 papers 连接到 topic questions 和 writing plans。
- 建立 authorized reading notes，并阻止 unauthorized/missing source 生成假 note。
- 建立 deterministic eval fixtures 和 trace summaries，让 regression 可见。

### 关键决策

- v1 storage layer 使用本地 Markdown/YAML，便于人工审阅和 git diff。
- Formal records 的权威性高于 agent outputs。
- `validate` 命令只读；`generate` / `propose` 可写 generated artifacts，但不得改 formal records。
- Formal writes 必须有人工确认，并通过 conflict-free validation。
- 用户可见文本以中文为主；schema names、CLI flags 和 YAML keys 保持英文稳定。
- Eval fixtures 必须是本地 deterministic checks，不依赖网络或 LLM judge。

### 延后事项

- Citation manager sync。
- Scholarly API integrations。
- Local Web UI。
- Large-scale batch literature processing。
- Claim-level citation checking for synthesis drafts。
- LLM-judged semantic evals。
- Full multi-agent orchestration。

### 技术债

- 部分早期 planning files 有编码痕迹；当前 README 和归档文档已改为中文优先的 UTF-8 文档。
- Markdown table parsers 对 v1 合适，但如果 formal records 变复杂，需要重新评估。
- Trace extraction 目前只支持已知 round artifacts。
